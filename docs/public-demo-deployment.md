# Public Demo Infrastructure Deployment Guide

## Overview
This document details the configuration, security controls, and verification workflow for deploying interactive public prototype landing pages generated by the AI Sales Prospecting System.

---

## 1. Architecture & Execution Modes

The prototype engine (`DemoGeneratorAgent`) operates in two execution modes:

### A. Local Development & Testing Mode (Default)
- **Environment Variable**: `PUBLIC_DEMO_BASE_URL` is **unset** or empty.
- **Behavior**:
  - Demos are generated at `static/demos/{lead_id}/index.html`.
  - Local preview URL is assigned: `http://localhost:8000/static/demos/{lead_id}/index.html`.
  - `public_demo_url` remains `None`.
  - `demo_access_status` and `demo_readiness` set to `LOCAL_ONLY`.
  - **Outreach Safety**: Localhost links are strictly excluded from generated prospect copy.

### B. Public HTTPS Production Mode
- **Environment Variable**: `PUBLIC_DEMO_BASE_URL` set to the public domain root (e.g. `https://demo.yourdomain.com` or `https://demos.antigravity.ai`).
- **Behavior**:
  - Prototype HTML generated as above.
  - Public demo URL formatted: `https://demo.yourdomain.com/static/demos/{lead_id}/index.html`.
  - 11-step security and reachability guard executed automatically prior to approval.
  - On verification pass: `public_demo_url` assigned, `demo_access_status` & `demo_readiness` set to `PUBLIC_ACCESSIBLE`.
  - On verification failure: `public_demo_url` set to `None`, status set to `PUBLIC_ACCESS_FAILED`.

---

## 2. Automated Verification Guard

Before any demo link is marked `PUBLIC_ACCESSIBLE` or inserted into outreach copy, `DemoGeneratorAgent.verify_demo_url()` validates the target URL against 6 strict criteria:

1. **Syntactical Validity**: URL scheme must be HTTP/HTTPS with non-empty netloc.
2. **HTTPS Enforcement**: Non-HTTPS URLs in production mode are immediately classified as `LOCAL_ONLY`.
3. **Private/Localhost IP Filtering**: Automatically rejects `localhost`, `127.0.0.1`, `0.0.0.0`, `192.168.x.x`, `10.x.x.x`, and `172.16-31.x.x`.
4. **HTTP Status Verification**: Executes real-time GET/HEAD HTTP check with 3.0s timeout. Status code must be `200 OK`.
5. **Sample Content Notice Check**: Response body must contain the mandatory system notice: `"SAMPLE / DEMO DATA"`.
6. **Mock Test Domain Handling**: Recognized mock domains (`.example.com`, `.test`) bypass live HTTP checks in unit tests.

## 3. Web Server & Static File Hosting Setup

To host public prototype demos securely using Nginx or Caddy reverse proxy:

### Nginx Static Location Configuration
```nginx
server {
    listen 443 ssl http2;
    server_name demo.yourdomain.com;

    ssl_certificate /etc/letsencrypt/live/demo.yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/demo.yourdomain.com/privkey.pem;

    # Restrict demo directory to static HTML and assets only
    location /static/demos/ {
        alias /var/www/sales_outreach_agent/static/demos/;
        autoindex off;
        add_header X-Content-Type-Options "nosniff";
        add_header X-Frame-Options "SAMEORIGIN";
        add_header Content-Security-Policy "default-src 'self' https://fonts.googleapis.com https://fonts.gstatic.com; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com;";
        
        # Disable execution of CGI/PHP scripts
        location ~ \.(php|pl|py|sh|cgi)$ {
            return 403;
        }
    }
}
```

## 4. Security & Data Isolation Controls

1. **Sanitization**: All business names, categories, addresses, and phone numbers rendered into prototype HTML templates undergo strict HTML entity escaping (`html.escape`).
2. **Path Traversal Protection**: Demo directory creation uses strictly validated UUID lead IDs (`os.path.join(base_static_dir, lead.id)`), avoiding user-controlled directory paths.
3. **Zero System Leakage**: Demo templates contain no backend credentials, API endpoints, internal IP addresses, or workflow metadata.
4. **Disclaimers**: Every generated prototype contains a mandatory footer notice:
   > **SAMPLE / DEMO DATA:** Prototype landing page generated exclusively for digital opportunity assessment for [Business Name].
